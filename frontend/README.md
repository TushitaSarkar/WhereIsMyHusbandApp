# Frontend (Next.js Dashboard)

This is the frontend dashboard for the Location Tracker app. It allows users to select and view device locations on a map in real time.

## Setup
- Node.js 18+
- Next.js (TypeScript)
- React
- Map library (e.g., Leaflet or Google Maps)

## Features
- Select a device to view its location
- Display device location on a map
- Fetches data from the FastAPI backend
